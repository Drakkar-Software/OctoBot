# Configuration

OctoBot's configuration is managed through the web interface and stored in the `user/` directory.

## Profiles

Profiles bundle a complete trading configuration: strategy, evaluators, exchanges, and trading pairs. Switch between profiles to quickly change your trading approach.

## Exchange Setup

Connect your exchange by providing API keys through the web interface. OctoBot supports 20+ exchanges including Binance, Bybit, OKX, Kraken, and more.

## Trading Pairs

Select which cryptocurrency pairs to trade. OctoBot supports any pair available on your connected exchange.

## Advanced Settings

- **Risk management**: Control position sizes and risk per trade
- **Notifications**: Configure alerts via Telegram, Discord, or email
- **Web interface**: Customize dashboard and interface settings
