Évaluateur qui capte les signaux des canaux Telegram.

Se déclenche sur un signal Telegram provenant de n'importe quel canal rejoint par votre compte personnel.

L'analyse des signaux est configurable en fonction du nom du canal.

Consultez la [documentation OctoBot sur le service API Telegram](https://www.octobot.cloud/en/guides/octobot-interfaces/telegram/telegram-api?utm_source=octobot&utm_medium=dk&utm_campaign=regular_open_source_content&utm_content=telegramChannelSignalEvaluator) pour plus d'informations.
