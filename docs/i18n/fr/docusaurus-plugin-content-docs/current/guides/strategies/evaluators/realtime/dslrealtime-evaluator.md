DSLRealtimeEvaluator est un évaluateur temps réel générique qui évalue une expression de condition DSL sur un canal de déclenchement configurable (OHLCV, Kline ou Ticker). Lorsque la condition est vraie, il émet une évaluation positive (+1) ; lorsqu'elle est fausse, il émet une évaluation négative (-1).
