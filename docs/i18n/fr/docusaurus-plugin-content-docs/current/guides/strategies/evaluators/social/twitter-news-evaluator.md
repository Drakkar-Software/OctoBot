Se déclenche lorsqu'un nouveau tweet apparaît depuis un compte Twitter listé dans TwitterNewsEvaluator.json.

Si l'évaluation d'un tweet donné est suffisamment significative, déclenche une réévaluation des stratégies. Sinon, 
agit comme un évaluateur d'arrière-plan.
