Analyse les tendances globales du marché crypto à partir des données de capitalisation boursière totale.

Cet évaluateur interprète des signaux de capitalisation boursière agrégés (par exemple, les valeurs historiques de capitalisation boursière,
les changements de tendance et les moyennes à long terme) afin de produire un score normalisé
indiquant des tendances de marché haussières ou baissières d'après les mouvements de capitalisation.

Source des données : ([API CoinDesk Data](https://developers.coindesk.com/documentation/data-api/overview_v1_latest_marketcap_all_tick))
