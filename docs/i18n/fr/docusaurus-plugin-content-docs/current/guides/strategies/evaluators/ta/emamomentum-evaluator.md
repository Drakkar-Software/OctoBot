Utilise les [moyennes mobiles exponentielles](https://www.investopedia.com/terms/m/movingaverage.asp) pour générer un signal lorsque le prix actuel dépasse la valeur moyenne.

Évalue -1 ou 1 lorsque le prix actuel est suffisamment éloigné de l'EMA.
