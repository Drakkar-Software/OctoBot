Analyse le sentiment global du marché crypto à partir d'articles d'actualité sur les cryptomonnaies.

Cet évaluateur interprète des signaux d'actualité agrégés (par exemple, les titres d'articles, leur contenu
et les classifications de sentiment) afin de produire un score normalisé
indiquant un sentiment de marché haussier ou baissier d'après la couverture médiatique récente.

Source des données : ([API CoinDesk Data](https://developers.coindesk.com/documentation/data-api/news))
