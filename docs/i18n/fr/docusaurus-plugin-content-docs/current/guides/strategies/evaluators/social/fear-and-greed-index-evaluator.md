Analyse le sentiment global du marché crypto à partir d'un Fear and Greed Index.

Cet évaluateur interprète des signaux de marché agrégés (par exemple, la volatilité, le volume/momentum,
le sentiment sur les réseaux sociaux, la dominance et les tendances) afin de produire un score normalisé
indiquant la peur ou l'avidité dominante.

Source des données : ([alternative.me](https://alternative.me/crypto/fear-and-greed-index/))
