RemoteTradingSignalsTradingMode trade en utilisant les signaux des stratégies communautaires auxquelles vous êtes abonné.

Note : par défaut, si vous n'atteignez pas les exigences minimales de l'exchange pour la taille d'ordre, 
la plus petite taille d'ordre possible sera utilisée. Cela peut être désactivé dans les options.

_Ce mode de trading prend en charge l'historique PNL lorsque l'émetteur du signal le prend également en charge._
